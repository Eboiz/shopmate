# PB-34 Search by Description or Photo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The shop page search bar finds products from a free-text description or a photo of a similar item, using PB-30's embedding service, and keeps working (keyword filter) when that service is off.

**Architecture:** The browser posts text and/or a shrunk photo to a new route `POST /api/shops/[slug]/search`. The route rate-limits, validates, and calls a `SemanticSearch` port: the HTTP adapter speaks the PB-30 `/search` wire contract (section 3.1 of the spec), a mock adapter stands in until PB-30 is merged. Hits are filtered to the shop's products and a score floor, and the page shows those products in order with the existing cards. Everything PB-30 will provide sits behind `src/lib/search/pb30-shim.ts` and `src/lib/search/embedder-contract.ts`, swapped in by Task 8 once PB-30 is on `main`.

**Tech Stack:** Next.js 16 (read `node_modules/next/dist/docs/` before touching routes), TypeScript, Zod 4, Supabase (Postgres, pgTAP), Vitest · Task 8 only: Python 3.12, uv, FastAPI, pytest (PB-30 `embedder/`).

**Spec:** `docs/superpowers/specs/2026-11-10-pb-34-describe-search.md` (AC1–AC6, A1–A5, R1–R4, contract §3).

## Review Focus

1. **Cold or down embedder** (Modal scaled to zero takes > 8 s, 5xx, bad JSON): text search keeps the instant keyword list with no error; photo search shows `photoUnavailable`. Tests: Task 3 `throws SemanticSearchUnavailable after SEARCH_TIMEOUT_MS`, Task 6 `embedder failure returns mode unavailable`, Task 7 `unavailable text search goes back to idle`.
2. **Hits of another shop or of a deleted product** (Qdrant not re-indexed after a catalog edit): dropped before the page sees them. Test: Task 4 `drops ids that are not products of the shop`.
3. **Late response of an older search** (Thảo submits, then submits again or clears before the first answer): the old answer never replaces the newer state. Test: Task 7 `ignores a response whose seq is not the latest`.
4. **iPhone HEIC and large phone photos** (Vercel 4.5 MB body limit): HEIC gets the type error; a valid 4.9 MB photo is shrunk before upload. Test: Task 2 `photoDecision` cases.
5. **Mock reaching production** (`SEARCH_EMBEDDER_MOCK=1` copied into Vercel): production never uses the mock. Test: Task 3 `semanticSearchFromEnv ignores the mock flag in production`.
